# فروشگاه اینترنتی ویپ و پاد 🚀

![Logo](https://via.placeholder.com/200x200/0ea5e9/ffffff?text=Vape+Store)

**توسعه داده شده توسط [سبحان](https://github.com/sobhankhandehroo8183-lab)**

یک فروشگاه اینترنتی مدرن و حرفه‌ای برای محصولات ویپ و پاد ساخته شده با React.js

## ✨ ویژگی‌ها

- 🎨 طراحی مدرن و واکنش‌گرا
- 🔐 احراز هویت کاربران
- 🛒 سبد خرید پیشرفته
- 💫 انیمیشن‌های روان
- 📱 کاملاً ریسپانسیو
- ⚡ سرعت بالا
- 🔍 جستجو و فیلتر پیشرفته
- 💬 نظرات کاربران
- 📝 وبلاگ و مقالات

## 🛠 تکنولوژی‌های استفاده شده

- React.js
- Tailwind CSS
- Framer Motion
- React Router
- React Hot Toast
- Hero Icons
- Vite

## 📦 نصب و اجرا

```bash
# کلون کردن پروژه
git clone https://github.com/sobhankhandehroo8183-lab/vape-store.git

# وارد شدن به پوشه پروژه
cd vape-store

# نصب وابستگی‌ها
npm install

# اجرا در محیط توسعه
npm run dev
